# Kits por rubro

Cada carpeta es un sitio de ejemplo completo para un rubro. Copia su contenido a `src/content/`.

| Kit | Para | Incluye |
|---|---|---|
| `profesional` | estudios contables, jurídicos, consultoras | portada, servicios, nosotros, testimonios, preguntas, contacto |
| `inmobiliaria` | inmobiliarias | propiedades con filtros y ficha, buscador, destacadas, página de tasaciones |

## Cómo aplicar un kit

En GitHub: pestaña **Actions** → **Aplicar kit** → **Run workflow** → elegí el kit → **Run workflow**.
En 1–2 minutos el sitio se publica con el contenido del kit. Después se personaliza desde Pages CMS.

> Atención: aplicar un kit reemplaza las páginas y el contenido actuales del sitio.

| `panaderia` | panaderías, cafés, rotiserías | catálogo por categorías con pedido por WhatsApp, página de encargos con precios, tema Sabor |
